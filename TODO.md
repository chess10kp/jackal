# Nanocoder parity gaps

The full feature matrix lives in **[docs/NANOCODER-PARITY.md](docs/NANOCODER-PARITY.md)**.

## Quick summary (2026-05-24)

**Done (Track A P0–P8):** Runtime boot, Ink TUI, dev modes, `@file`/`!cmd`, `/explorer`, sessions, LLM compaction, checkpoints, tasks, subagents, custom commands, `jackal run`.

**Partial:** Tool approval UI (banner vs rich dialog), gitignore-aware search, model-aware token counting, markdown text wrapping.

**Missing / deferred:** Custom tools, scheduler, `/tune`, VS Code bridge, model database, web search/fetch, dedicated git/file-op tools, task/checkpoint Ink overlays.

See the parity doc for the complete table with nanocoder source references and recommended priorities.
